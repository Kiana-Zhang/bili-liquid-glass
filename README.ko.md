# Bili Liquid Glass

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

Bilibili 동영상과 시리즈 시청 페이지에 영상 색상에 따라 변하는 앰비언트 조명과 투명도를 조절할 수 있는 유리 테마를 추가합니다. 데스크톱 Chrome과 Edge를 지원하며 영상은 기기에서만 처리합니다.

**소스 버전: 0.1.23 · 소스 공개 · 비상업적 라이선스**

## 다운로드 및 설치

[Chrome / Edge 확장 프로그램 다운로드](https://github.com/Kiana-Zhang/bili-liquid-glass/releases)

Releases에서 브라우저와 버전에 맞는 ZIP을 선택하세요. GitHub의 “Source code”는 소스 코드 압축 파일입니다. 설치에는 Chrome 또는 Edge 확장 프로그램 ZIP을 사용하세요.

1. ZIP을 계속 보관할 폴더에 압축 해제합니다.
2. Chrome에서 `chrome://extensions`, Edge에서 `edge://extensions`를 엽니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. `manifest.json`이 바로 들어 있는 폴더를 선택합니다.
5. 이미 열려 있는 Bilibili 시청 페이지를 새로고침합니다.

브라우저가 해당 폴더에서 확장 프로그램을 불러오므로 폴더를 보관하세요. 설치에는 개발자 모드가 필요하지만 평소에는 명령어나 Node.js가 필요하지 않습니다.

## 기능

- 영상의 색상을 주변에 부드럽게 확산하며 자르거나 늘리지 않고 전체 영상을 유지합니다.
- 탐색 메뉴, 정보 영역, 사이드바, 댓글과 일반 팝업에 유리 테마를 적용합니다.
- 시스템의 밝은/어두운 테마를 따르거나 직접 선택할 수 있습니다.
- 일반, 와이드, 웹 전체 화면, 브라우저 전체 화면을 지원합니다. 전체 화면에서는 영상 바깥 공간에 조명을 표시합니다.
- 일시 정지하면 마지막 조명을 유지합니다. 숨겨진 탭, 화면 속 화면, 작은 플레이어에서는 동적 영상 샘플링을 중지합니다.

**몰입형 조명**을 켜면 일부 광고, 이벤트 영역과 투표도 숨깁니다. 웹사이트의 모든 광고를 대상으로 하지는 않습니다.

## 효과 설정

도구 모음의 확장 프로그램 아이콘이나 플레이어의 **✦ 조명**을 클릭하세요. 아이콘이 보이지 않으면 확장 프로그램 메뉴에서 고정할 수 있습니다.

| 설정 | 설명 |
| --- | --- |
| 언어 | 패널 상단에서 简体中文, English, 日本語, 한국어를 선택합니다. 즉시 적용되고 저장됩니다. 기본값은 중국어 간체입니다. 조명이 꺼져 있어도 변경할 수 있으며 기본값 복원 시에도 언어는 유지됩니다. |
| 몰입형 조명 | 조명과 유리 테마를 함께 켜거나 끕니다. 끄면 원래 모습으로 돌아갑니다. |
| 투명도 | 높을수록 유리가 투명해지고 조명이 강해집니다. 기본값은 65입니다. 0에서는 조명이 사라지지만 배경 흐림은 유지됩니다. |
| 확산 범위 | 바깥으로 퍼지는 거리를 0–200에서 조절합니다. |
| 부드러움 | 조명 전환과 가장자리의 부드러움을 조절합니다. |
| 확산 방향 | 직선 또는 대각선 투영을 선택합니다. |
| 테마 | 시스템 설정, 밝은 유리, 어두운 테마를 선택합니다. |
| 성능 | 기본값은 균형입니다. 기기 부담을 줄이려면 절전, 세밀한 조명을 원하면 정밀을 선택합니다. |

패널 바깥을 클릭하거나 Esc를 누르면 닫힙니다. 변경은 자동 저장되고 페이지 패널과 확장 프로그램 팝업이 공유합니다. Chrome과 Edge의 설정은 각각 저장되며 계정 동기화는 하지 않습니다.

## 지원 범위 및 제한

- `www.bilibili.com/video/*`의 일반 동영상과 `www.bilibili.com/bangumi/play/*`의 애니메이션, 시리즈, 영화 페이지를 지원합니다.
- 데스크톱 Chrome과 Edge를 지원합니다. 명시된 최소 Chromium 버전은 121이며 현재 안정 버전을 권장합니다. 최소 버전의 모든 기능을 실제 기기에서 검증하지는 않았습니다.
- 라이브 방송 도메인, 홈페이지 테마, 모바일 브라우저와 외부 임베디드 플레이어는 지원 범위 밖입니다.
- 영상 자체의 검은 여백도 색상 확산에 포함되며 자동으로 자르지 않습니다. 현재 HDR 전용 보정은 없습니다.
- 웹사이트 개편, 계정별 페이지 차이와 다른 테마/플레이어 확장 프로그램이 효과에 영향을 줄 수 있습니다.

## 업데이트 및 제거

**업데이트:** 새 ZIP을 기존 설치 폴더에 압축 해제해 파일을 교체합니다. 관리 페이지에서 **새로고침**을 클릭한 뒤 Bilibili를 새로고침하세요. 같은 폴더를 사용하면 설정이 유지됩니다.

**잠시 끄기:** 몰입형 조명을 끄거나 관리 페이지에서 확장 프로그램을 비활성화하고 Bilibili를 새로고침합니다.

**제거:** 관리 페이지에서 **삭제**를 선택하고 Bilibili를 새로고침합니다. 브라우저가 저장된 설정을 지웁니다. 압축 해제 폴더는 직접 삭제할 수 있습니다.

## 문제 해결

**설치 후 변화가 없나요?** 확장 프로그램과 몰입형 조명이 켜져 있는지 확인한 뒤 지원 페이지를 새로고침하세요. 설치나 확장 프로그램 새로고침 후 기존 페이지도 새로고침해야 합니다. 사이트 접근이 제한된 경우 `www.bilibili.com`을 허용하세요.

**유리 테마는 보이지만 동적 조명이 없나요?** 투명도가 0인지 확인하세요. 영상 읽기 제한이나 보호된 미디어는 동적 조명을 중지하고 이유를 표시하지만 유리 테마는 유지됩니다. 영상이 전체 화면을 채우면 주변 조명 공간이 없습니다. 작은 플레이어와 화면 속 화면에서도 동적 샘플링을 중지합니다.

**끊김, 배터리 소모 또는 팬 소음이 있나요?** 절전 모드를 선택하거나 조명을 잠시 끄세요. 기기, 해상도와 다른 확장 프로그램에 따라 성능이 달라집니다.

**레이아웃이나 글자가 이상한가요?** 조명을 끄고 새로고침한 뒤 다른 확장 프로그램과의 충돌을 확인하세요. [GitHub Issues](https://github.com/Kiana-Zhang/bili-liquid-glass/issues)에 브라우저 버전, 페이지, 재현 단계와 설정을 첨부할 수 있습니다. 이미지의 개인정보는 가려 주세요.

## 개인정보 및 자율 후원

영상은 기기에서 처리하며 업로드하거나 스크린샷으로 저장하지 않습니다. 설정은 현재 브라우저에만 저장됩니다. 시청 기록, 계정 정보나 기기 통계를 수집하지 않으며 원격 측정과 분석 서비스도 없습니다. [개인정보 안내](PRIVACY.md)(중국어 간체)를 참고하세요.

## 소스에서 빌드

Node.js를 설치한 뒤 프로젝트에서 `npm ci`와 `npm run build`를 실행하고 `dist/chrome` 또는 `dist/edge`를 로드하세요. `npm run check`는 타입, 단위 테스트, 빌드와 브라우저 회귀 테스트를 실행합니다. `npm run test:i18n`은 4개 언어, 저장 및 동기화, 좁은 패널 레이아웃을 확인합니다. 소스가 Releases보다 앞선 경우 로컬 빌드로 새 기능을 사용할 수 있습니다.
