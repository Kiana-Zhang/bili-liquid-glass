# Bili Liquid Glass

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

Bilibiliの動画・アニメ視聴ページに、映像の色に合わせて変化するアンビエントライトと、透明度を調整できるガラステーマを追加します。デスクトップ版ChromeとEdgeに対応し、映像は端末内でのみ処理します。

**ソース版：0.1.23 · ソース公開 · 非商用ライセンス**

## ダウンロードとインストール

[Chrome / Edge用拡張機能をダウンロード](https://github.com/Kiana-Zhang/bili-liquid-glass/releases)

Releasesからブラウザーとバージョンに対応するZIPを選んでください。「Source code」はソースコードのアーカイブです。インストールにはChrome / Edge用ZIPを使用します。

1. ZIPを継続して保存するフォルダーに展開します。
2. Chromeでは`chrome://extensions`、Edgeでは`edge://extensions`を開きます。
3. 「デベロッパーモード」をオンにし、「パッケージ化されていない拡張機能を読み込む」を選びます。
4. `manifest.json`が直接入っているフォルダーを選びます。
5. 開いているBilibiliの視聴ページを再読み込みします。

ブラウザーは展開先から拡張機能を読み込むため、フォルダーを残してください。インストールにはデベロッパーモードが必要ですが、普段の使用にコマンドやNode.jsは不要です。

## 機能

- 映像の色を周囲に柔らかく拡散し、切り抜きや引き伸ばしなしで動画全体を表示します。
- 視聴ページのナビゲーション、情報欄、サイドバー、コメント、一般的なポップアップにガラステーマを適用します。
- システムの明暗設定に従うほか、ライト・ダークを手動選択できます。
- 通常、ワイド、ページ全画面、ブラウザー全画面に対応します。全画面では動画の外側の空間にライトを表示します。
- 一時停止時は最後のライトを維持し、非表示のタブ、ピクチャーインピクチャー、小窓表示では動的な映像取得を停止します。

「没入型ライト」をオンにすると、一部の広告、キャンペーン枠、投票も非表示になります。サイト内のすべての広告が対象ではありません。

## 効果の調整

ツールバーの拡張機能アイコン、またはプレイヤーの「✦ ライト」をクリックします。アイコンが見つからない場合は拡張機能メニューから固定できます。

| 設定 | 説明 |
| --- | --- |
| 言語 | パネル上部で简体中文、English、日本語、한국어を選びます。即時に反映・保存されます。初期設定は簡体字中国語です。ライトがオフでも変更でき、初期設定への復元時も言語は維持されます。 |
| 没入型ライト | ライトとガラステーマをまとめて切り替えます。オフにすると元の外観に戻ります。 |
| 透明度 | 高いほどガラスが透明になり、ライトが強くなります。初期値は65。0ではライトが消えますが、背景のぼかしは残ります。 |
| 拡散範囲 | 外側へ広がる距離を0〜200で調整します。 |
| 柔らかさ | フェードの柔らかさを調整します。 |
| 拡散方向 | まっすぐ、または斜めの投影を選びます。 |
| 外観 | システムに従う、ライトガラス、ダーク。 |
| 描画品質 | 初期設定はバランス。負荷を抑えるなら省電力、細かなライトを求めるなら高精細を選びます。 |

パネルの外側をクリックするかEscで閉じます。変更は自動保存され、ページのパネルと拡張機能ポップアップで共有されます。ChromeとEdgeは別々に保存し、アカウント同期は行いません。

## 対応範囲と制限

- `www.bilibili.com/video/*`の通常動画と、`www.bilibili.com/bangumi/play/*`のアニメ・ドラマ・映画に対応します。
- デスクトップ版Chrome・Edgeに対応します。宣言上の最低Chromium版は121ですが、現在の安定版を推奨します。最低版での全機能の実機検証は完了していません。
- ライブ配信ドメイン、ホームページのテーマ、モバイルブラウザー、外部埋め込みプレイヤーは対象外です。
- 映像内の黒帯も拡散に含まれ、自動的に切り抜きません。HDR専用の補正は現在ありません。
- サイトの変更、アカウントごとのページ差分、他のテーマ・プレイヤー拡張機能が結果に影響する場合があります。

## 更新とアンインストール

**更新：** 新しいZIPを既存のフォルダーに展開して上書きし、管理ページで「再読み込み」をクリックしてからBilibiliを再読み込みします。同じフォルダーを使うと設定を維持できます。

**一時停止：** 「没入型ライト」をオフにするか、管理ページで拡張機能を無効にしてBilibiliを再読み込みします。

**削除：** 管理ページで「削除」を選び、Bilibiliを再読み込みします。設定はブラウザーが消去します。展開フォルダーは自分で削除できます。

## よくある質問

**変化がない：** 拡張機能と「没入型ライト」が有効か確認し、対応するページを再読み込みしてください。インストール・再読み込み後は既存ページの再読み込みも必要です。サイトアクセスが制限されている場合は`www.bilibili.com`を許可してください。

**ガラスは表示されるが動的ライトがない：** 透明度が0でないか確認してください。読み取り制限や保護されたメディアの場合、ライトを停止して理由を表示しますが、ガラステーマは利用できます。全画面動画が画面を埋める場合、ライトを表示する空間がありません。小窓やピクチャーインピクチャーでも動的取得を停止します。

**動作が重い、消費電力やファン音が増える：** 省電力を選ぶか、一時的にライトをオフにしてください。機器、解像度、他の拡張機能により性能は異なります。

**レイアウトや文字がおかしい：** ライトをオフにして再読み込みし、他の拡張機能との競合を確認してください。[GitHub Issues](https://github.com/Kiana-Zhang/bili-liquid-glass/issues)にブラウザー版、URL、手順、設定を添えて報告できます。画像の個人情報は隠してください。

## プライバシーと任意の支援

映像は端末内で処理し、アップロードやスクリーンショット保存を行いません。設定は現在のブラウザー内に保存します。視聴履歴、アカウント情報、端末統計は収集せず、テレメトリーや分析サービスもありません。[プライバシー説明](PRIVACY.md)（簡体字中国語）をご覧ください。

支援は完全に任意で、機能には影響しません。拡張機能内のAlipay・WeChat用QRコードは端末内で生成します。PayPalアイコンはKo-fiを開きます。決済は各アプリ・サイトが処理し、拡張機能は自動支払いや決済情報の読み取りを行いません。

## ソースからのビルド

Node.jsをインストールし、プロジェクト内で`npm ci`と`npm run build`を実行します。`dist/chrome`または`dist/edge`を読み込みます。`npm run check`で型・単体テスト・ビルド・ブラウザー回帰を、`npm run test:i18n`で4言語・保存と同期・狭いパネルのレイアウトを確認します。ソースがReleasesより新しい場合はローカルビルドで新機能を試せます。
